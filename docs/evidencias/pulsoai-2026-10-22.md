## Fallo de concurrencia general: no ocultado

La prueba existente JOINT-CONC-08 exige menos de 5000 ms al finalizar mientras llegan cinco muestras. Primer ensayo: 6838 ms; repetición serial: timeout de prueba de 10000 ms. No se amplió su presupuesto ni se modificó la prueba para aprobarla.

Comparación adicional en un emulador desechable aislado, mismo fixture, carga transaccional y runtime: se transpila en memoria el repositorio de sesiones de `main` sin PulsoAI y se contrasta con el actual. **Main sin cambios: 11206 ms; PulsoAI: 7172 ms.** Ambos conservaron conteos correctos y cierre exitoso. Una corrida por variante no demuestra mejora o equivalencia estadística; sí reproduce que el umbral también falla en la base sin PulsoAI. Relacionado con #51/#32. No representa latencia de nube.

Por esto no se declara la suite general completamente verde ni se cierra #72. Se mantiene PR en borrador para revisión.

## Reproducir

Desde raíz, PowerShell; Java 21 y Node 24. Dependencias del repositorio instaladas. `apps/api/.env` debe tener una clave Groq privada; seleccionar plan Free. El runner exige proyecto demo- y hosts de emuladores locales, no opera sobre Firestore cloud. Playwright debe estar instalado/disponible; `PULSOLINK_PLAYWRIGHT_MODULE` acepta una ruta absoluta local al módulo. No instala navegadores ni cambia planes.

~~~powershell
npx --yes --package=node@24 --call 'npm run typecheck && npm run build:deploy'
$env:FIREBASE_PROJECT_ID='demo-pulsoai-qa'
$env:NODE_ENV='test'
npx --yes --package=node@24 --package=firebase-tools --call 'firebase emulators:exec --only firestore,auth --config firebase/emulators.test.json --project demo-pulsoai-qa "npm test --workspace=apps/api -- --fileParallelism=false"'

$env:FIREBASE_PROJECT_ID='demo-pulsoai-browser'
$env:PULSOAI_QA_ALLOW_REAL_GROQ='true'
# Si no se resuelve playwright, configurar PULSOLINK_PLAYWRIGHT_MODULE con su ruta local.
npx --yes --package=node@24 --package=firebase-tools --call 'firebase emulators:exec --only firestore,auth --config firebase/emulators.test.json --project demo-pulsoai-browser "node tools/qa/pulsoai-acceptance.cjs"'
~~~

La ejecución registrada utilizó copias de configuración ignoradas con puertos alternativos para evitar colisionar con otros emuladores: API 18001, Firestore 38080, Auth 39099. Los comandos anteriores usan los puertos estándar del archivo de pruebas si están libres. El runner guarda reportes/capturas en `.cache/pulsoai-browser` y cada repetición consume una solicitud real; no reintenta automáticamente ni ejecuta consultas a Firebase real.
