## HTTP real

[Reporte completo](hugo-pl2-http.json) y [matriz/procedimiento](../qa/pl2-08-hugo.md).
Los endpoints oficiales aún rechazan deviceId en heartbeat/MeasurementInput (400). Credencial ausente/inválida devuelve 401 con código anterior. PATCH patients y GET assignments dan 404. Por ello no se envían datos del simulador al dashboard real en esta revisión, ni se acredita el recorrido completo nuevo o su reconexión. Se conserva el contrato aprobado sin debilitar el simulador para ocultar la incompatibilidad.

La historia presembrada sí se consultó vía login, API y Firestore: 48 lecturas en dos placas sin cruce al paciente B. El viewer no puede consultar auditoría (403). El 404 en PATCH no acredita la autorización que debe existir cuando se publique esa ruta.

## Interfaz real y evidencia

[Resultados de navegador](hugo-ui/results.json). Script: `tools/qa/hugo-ui.cjs`.
Login real de viewer, dashboard de `monitor-patient`, 100 → 200 → 240 lecturas, cobertura parcial/completa, ambas placas, null mostrado con raya y Sin contacto, stale/desconectado, origen simulado, recarga conservando historia, paciente vacío, ausencia de botón de creación para viewer y una transición de foco por teclado. La comprobación de ancho mide desbordamiento del documento; no es auditoría exhaustiva de accesibilidad o diseño. La tabla conserva su desplazamiento horizontal intencional.

Se usa Edge headless instalado, con Playwright instalado fuera del repositorio para no modificar dependencias compartidas. Ejemplo reproducible desde raíz, con QA_PASSWORD/QA_VIEWER_EMAIL del fixture:

```powershell
# Instalar herramienta en una carpeta local ignorada, no en el package.json compartido
npm install --prefix .cache/qa-browser --no-save playwright
$env:NODE_PATH=Join-Path (Get-Location) '.cache/qa-browser/node_modules'
$env:QA_PASSWORD=$env:DEMO_FIXTURE_PASSWORD
$env:QA_RUN_WEB_TESTS='true'
node tools/qa/hugo-ui.cjs
```

El script pasa la cookie al proceso hijo por entorno y no la escribe en reportes. QA_BROWSER permite elegir otro canal instalado. Advertencias existentes de React Router y dimensiones de Recharts bajo jsdom no impidieron la suite. No hubo datos de pacientes reales.
